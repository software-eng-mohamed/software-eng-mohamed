## 🧭 How I Approach Development

- **Understand the problem:** clarify requirements and consider the user's experience before implementation.
- **Keep code maintainable:** use clear naming, focused modules, and consistent patterns.
- **Handle failure properly:** validate inputs, manage errors, and provide useful feedback.
- **Build security into features:** consider authentication, permissions, and data handling from the start.
- **Verify the result:** test important behavior and review changes before shipping.
- **Document what matters:** make setup, API behavior, and technical decisions easier to understand.
